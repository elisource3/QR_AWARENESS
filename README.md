# QR_AWARENESS
QR Code realizzato per una campagna di ingegneria sociale, per testare la consapevolezza dei soggetti a riguardo del phishing tramite QR-code, posizionati in luoghi pubblici. Il progetto non rende possibile la ricezione di dati sensibili, rimanendo anonimo e con l'unico obiettivo di realizzare una statistica inerente all'ambito cybersecurity.
